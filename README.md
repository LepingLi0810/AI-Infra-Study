# AI-Infra-Study

A study and research notebook for moving from computer systems into LLM inference infrastructure.

Starting background: concurrency, synchronization, distributed systems, RDMA, and resource scheduling. The goal is to turn that experience into practical expertise in GPU execution, inference serving, and performance engineering over the year before graduation.

Start with the [12-month study plan](STUDY_PLAN.md). It includes monthly milestones, hands-on experiments, reading priorities, and a capstone on inference scheduling under latency and memory constraints.

Begin the hands-on work with [month 1, week 1: tensors and your first GPU operation](experiments/month01/week01-tensors/README.md).

[AGENTS.md](AGENTS.md) contains shared project context and working instructions for agents across development machines. Commit and sync it with the study materials; each machine still needs its own runtime setup.

Use this repository to keep explanations, runnable experiments, reproducible measurements, and research decisions together. Prefer a small number of well-understood results over a large reading list.
